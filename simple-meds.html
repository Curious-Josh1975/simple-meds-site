Install on Android

  1. Tap Download APK and wait for the file to finish.
  2. Open the downloaded file. If Android blocks it, allow installs from this browser or Files app under Install unknown apps.
  3. Confirm the install. You may see an unknown-source warning; that is normal for a direct APK.
  4. Open Simple Meds and allow notifications (and Alarms & reminders if prompted) so dose times can ring.

Always download from this site or a link you trust. Prefer HTTPS. Updates are not automatic from this page.
